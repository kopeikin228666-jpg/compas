КОМПАС — личный маршрут
======================

В комплекте: готовое психологическое мини-приложение на 30 шагов.
Оно не требует аккаунта или сервера для хранения дневника.

КАК ЗАПУСТИТЬ СРАЗУ НА КОМПЬЮТЕРЕ
Открой index.html в Chrome, Edge или Firefox.
Не перемещай файл в другое место или другой браузер без резервной копии записей.

КАК ПОЛУЧИТЬ ПОСТОЯННУЮ ССЫЛКУ И ЯРЛЫК НА ТЕЛЕФОНЕ
1. Создай новый публичный репозиторий на GitHub (например kompas-route).
2. Загрузи в корень репозитория все пять файлов из этой папки.
3. В Settings → Pages выбери Deploy from a branch, main, / (root) и Save.
4. Открой опубликованный адрес с телефона через Safari (iPhone).
5. Нажми Поделиться → На экран «Домой».

Эта версия умеет работать офлайн после первоначальной загрузки с сайта.

ВАЖНО О ПРИВАТНОСТИ
Публикуется только код программы; личные записи НЕ публикуются на GitHub.
Они хранятся локально в браузере, в localStorage и не синхронизируются между устройствами.
Используй Дневник → Скачать копию .json для резервного копирования.
Переход с локального index.html на GitHub Pages — другой адрес хранения: импортируй копию на новом сайте.
Не размещай свои JSON-копии дневника в публичном GitHub-репозитории.

КАК ПОЛУЧИТЬ НОВЫЙ ПЛАН ОТ CHATGPT
Открой раздел «План от GPT», скопируй запрос, отправь его в чат и вставь ответ из 3 строк обратно.
Приложение не подключено к ChatGPT автоматически.

ПРИМЕЧАНИЕ
Программа помогает структурировать повседневность и размышления, но не заменяет диагностику или лечение.
Повторяющиеся провалы в памяти и дезориентация требуют срочной очной медицинской оценки.
